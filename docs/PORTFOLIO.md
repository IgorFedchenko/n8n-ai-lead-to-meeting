# Portfolio example

**Title (51 characters):** AI Lead Qualification & Meeting Automation with n8n

**Description:** Built a working reference implementation that turns web-form and email inquiries
into structured AI qualifications, HubSpot contacts and deals, and booked Google Calendar meetings
with email confirmations. The stack combines n8n, Python and Postgres with idempotent delivery,
bounded retries, a manual review queue, an independent error workflow and reproducible CI tests.
The local demo uses synthetic data and API mocks; live adapters are included for operator configuration.
